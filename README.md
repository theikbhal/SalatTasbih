# SalatTasbih (macOS, SwiftUI)
Requires macOS 13+ and Xcode / Command Line Tools (`xcode-select --install`).
1. Unzip, open Terminal in the folder, run `./install.sh` (copies to ~/workspace/SalatTasbih and starts the app).
2. Later: `cd ~/workspace/SalatTasbih && ./run.sh`, or `open Package.swift` in Xcode and press ⌘R.
